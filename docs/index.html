Utilitário Rust

dbc2dbf 🦀

Utilitário de linha de comando de alta velocidade escrito em Rust para converter e descompactar arquivos DATASUS DBC em DBF.

Instruções de Uso

Descompactação direta via CLI:

cargo build --release
./target/release/dbc2dbf arquivo.dbc arquivo.dbf

Desenvolvimento Local

Consulte as instruções de ambiente unificado no repositório privado workspace:

cd ~/projetos/PESSOAL/abrasileirado/workspace
./abrasileirado help
